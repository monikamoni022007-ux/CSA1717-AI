
Artificial Intelligence – Assessment 1

TITLE
Analytical Problem Solving using Intelligent Agents and Search Algorithms

OBJECTIVE
To understand and analyze different types of Intelligent Agents and Artificial Intelligence search algorithms by applying them to real-world problem scenarios. The assessment aims to evaluate how AI techniques support autonomous decision-making, optimization, pathfinding, and intelligent system design.

SOFTWARE USED
Python 3.13 (for implementation, if required)

TOOLS USED
Python IDLE
Google Classroom 
Microsoft Word (Documentation)

ALGORITHMS
Simple Reflex Agent
Model-Based Agent
Goal-Based Agent
Utility-Based Agent
Uniform Cost Search (UCS)
Iterative Deepening Search (IDS)

PROBLEM IMPLEMENTED
Smart Home Automation System using Intelligent Agents
Analysis of Simple Reflex, Model-Based, Goal-Based, and Utility-Based agents.
Selection of the most suitable hybrid intelligent agent for improving comfort, energy efficiency, and home security.
Robot Navigation in an Unknown Maze
Application of Uniform Cost Search (UCS) to determine the least-cost path.
Application of Iterative Deepening Search (IDS) to explore the maze with limited memory.
Comparison of UCS and IDS based on time complexity, space complexity, optimality, and decision-making.
Recommendation of the most effective intelligent agent and search strategy for autonomous robot navigation.

RESULT
Successfully analyzed and evaluated intelligent agent models and AI search algorithms for solving real-world problems. The assessment demonstrated how different agent architectures and search strategies contribute to autonomous decision-making, path optimization, efficient resource utilization, and intelligent problem-solving. The study concluded that a Hybrid Intelligent Agent is the most effective solution for smart home automation, while a Goal-Based Agent integrated with Uniform Cost Search (UCS) provides the most efficient approach for robot navigation in environments with varying path costs.

Title:
Analytical Problem Solving using Artificial Intelligence Search Algorithms

Objective:
To solve real-world analytical problems using Artificial Intelligence search algorithms and intelligent agent concepts by implementing efficient search techniques in Python.

Software:
- Python 3.13

Development Tool:
- Python IDLE

Algorithms Implemented:
1. Backtracking Search
2. Breadth First Search (BFS)
3. Uniform Cost Search (UCS)

Programs Included:
1. Doctor Shift Scheduling using Backtracking Search
   - Assigns doctors to shifts while satisfying scheduling constraints.

2. Robot Grid Navigation using Breadth First Search (BFS)
   - Finds the shortest path for a robot to reach the destination in a grid.

3. Autonomous Rescue Robot using Uniform Cost Search (UCS)
   - Determines the minimum-cost path for a rescue robot to reach a target location.

Features:
- Constraint-based scheduling
- Shortest path finding
- Cost-optimized path planning
- Simple and easy-to-understand Python implementation

Outcome:
The implemented AI search algorithms successfully solved the given analytical problems. Backtracking produced valid schedules, BFS identified the shortest route, and UCS determined the least-cost path, demonstrating the practical application of Artificial Intelligence search techniques.
